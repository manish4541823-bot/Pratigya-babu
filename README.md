# Little Love 💗

A tiny, responsive love-themed website made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — styling and animations
- `script.js` — interactive love-message button
- `assets/heart.svg` — lightweight favicon

## Run locally
Open `index.html` in a browser.

## Host on GitHub Pages
1. Create a GitHub repository.
2. Upload all files and keep the `assets` folder in the same place.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

No build step required. The page is lightweight; the only optional network dependency is Google Fonts. If you want it fully offline, remove the `@import` line at the top of `style.css` and it will use system fallback fonts.
